# Project logo

An original painted fantasy-item logo in the same family as Lorekeeper's Codex,
Yonder, Hearthtale and Second Wind. Generated using the
built-in image generation tool.

A heavy brass ring gathers three keys, with warm gold, turquoise and emerald
accents against a deep navy background.

- `logo-master.png`: full-resolution generated master, 1254px square.
- `logo-1024.png`: 1024px square, for the CurseForge project page.
- `logo.png`: 512px square export.
- `logo-prompts.json`: the generation prompt and sibling logos consulted for style.
- `../addon/Keyring/Media/Logo.tga`: uncompressed 256px texture with rounded
  corners (radius 34), used by the addon listing and minimap button.
